🤟 ASL Interpreter

Webcam-based ASL alphabet recognition. I integrated the team's CNN into a Python inference pipeline, handling webcam capture, hand isolation, image preprocessing, and timed letter output.

Python PyTorch Computer Vision

♻️ EcoLoop

A tool for evaluating business ideas through a circular-economy lens. Used Cohere for classification and LangChain with Pinecone for retrieval-augmented scoring and explanations across feasibility, market potential, scalability, and maturity.

Python Cohere LangChain Pinecone RAG

🏆 VoiceMintify

Best Use of Hedera — Web3Apps. Our team built a chatbot with facial recognition and NFT minting. I implemented NFT creation and minting on Hedera testnet, including transaction signing and metadata submission.

JavaScript Hedera SDK NFT Minting

🌍 VaxOptima

Interactive visualizations of vaccination coverage and allocation simulations. Built an animated world map with timeline controls and a chart tracking optimization progress across 100 genetic-algorithm generations toward a simulated 70% global vaccination target.

Python Pandas GeoPandas Plotly
